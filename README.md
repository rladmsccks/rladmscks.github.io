# 자료구조 · 알고리즘 스터디 노트

강의별 핵심 내용과 키워드를 카드로 정리한 정적 학습 홈페이지입니다.

- `index.html`을 브라우저에서 열어 확인할 수 있습니다.
- 강의 데이터는 `script.js`의 `lessons` 배열에 있습니다.
- 강의 순서순·제목순 버튼을 누르면 오름차순으로 정렬하고, 같은 버튼을 다시 누르면 내림차순으로 전환합니다. 두 정렬 모두 `script.js`의 `mergeSort`를 사용합니다.
- 강의 카드를 클릭하면 같은 강의 번호의 PDF 학습 가이드가 새 탭에서 열립니다.
- `연관 트리` 보기에서 강의 주제 간 관계를 계층 형태로 확인하고, 각 강의 PDF를 열 수 있습니다.
- 외부 이미지, API, 라이브러리 없이 동작합니다.
